# API reference

MIReasy exposes one class per level of the data hierarchy — `Stimulus` (one
audio file), `Session` (a folder of files), `Participant` (a folder of
sessions) — plus the `mireasy()` dispatcher, which inspects a path and returns
the right one. The pages below are generated from the code's docstrings.
