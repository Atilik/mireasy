# API reference

MIReasy has one class per level of the data hierarchy: `Stimulus` (one audio
file), `Session` (a folder of files) and `Participant` (a folder of sessions).
The `mireasy()` function looks at a path and returns the right one. The pages
below are generated from the code's docstrings.
